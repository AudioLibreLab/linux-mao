# Grooves GrooveScribe

Grooves funk et jazz à ouvrir dans GrooveScribe. Ce sont des versions simplifiées, faites pour jouer par-dessus, pas des relevés exacts.

Les grooves swing, la valse et le shuffle sont écrits en triolets (Div=12), donc le swing est dans la grille elle-même. Pour les importer dans Hydrogen : `hydrogen/groovescribe2h2.py SONG.h2song NOM URL ...`
